## 🚀 How to Host on GitHub (Free & Live in 3 Minutes)

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com) and click **New Repository**.
   - Name it something cute like `happy-birthday-bebe` or `for-my-bebe`.
   - Set it to **Public** and click **Create repository**.

2. **Upload Your Files**:
   - Upload all files from this folder:
     - `index.html`
     - `style.css`
     - `script.js`
     - `assets/` folder (including `photos/` and `video/`)
   - Commit changes.

3. **Enable GitHub Pages**:
   - In your repository, click **Settings** (top tab).
   - In the left sidebar, click **Pages**.
   - Under **Build and deployment > Branch**, select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.
   - Within 60 seconds, your site will be live at:
     `https://<your-username>.github.io/happy-birthday-bebe/`

### 2. Adding Your Video:
- Place your video file inside `assets/video/` and name it:
  `bebe_birthday_video.mp4`
- **Alternative (YouTube/Drive Link)**:
  If your video is hosted on YouTube or Google Drive, you can replace the `<video>` tag in `index.html` (under Page 10) with an `<iframe>` embed!
